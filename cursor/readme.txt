Cartoonish Set
==============

Author:
  - darkeye90
    https://ko-fi.com/darkeye

Notes:
Cartoonish is a classic and modern cursor theme inspired by Zen custom cursor (Silver).

I created it using Inkscape.

I hope you like it.

If you find anything off please contact me.

Installation:
  1. Right-click install.inf
  2. Select 'Install'
  3. Open Control Panel > Mouse > Pointers
  4. Select 'Cartoonish Set' from the Scheme dropdown
